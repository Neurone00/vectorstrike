# Original crew markings v001

Use `SV_GFX_Markings_Atlas_v001.png` for the transparent 2048×1024 atlas, or the eight individual 512×512 PNGs. Matching SVGs provide editable source artwork. JSON supplies atlas cell positions and UV bounds.

All graphics are original flat base ink, with no baked lighting or material shadows. The crew arrow has simple drip accents. Apply wear through the vehicle/track material or an authored paint mask rather than assuming these are complete gritty vehicle textures.

The preview sheet under `production/references/` is a labeled presentation, not a texture. Do not import it as the atlas. Numbers in SVG use Arial Bold; the PNGs preserve the intended appearance without font dependencies. These files have not been imported or tested in Unity.

Color intent: bone numbers/tallies, acid-lime crew tag, mustard directions, mustard/graphite hazard patch. Keep graffiti sparse and essential race markings readable.
